# 🧮 CLI Calculator

A command-line calculator built using **C++**. This project is part of my journey learning C++ programming, focusing on basic arithmetic, mathematical operations, control flow, and input handling.

## 🚀 Features

- Addition (`+`)
- Subtraction (`-`)
- Multiplication (`*`)
- Division (`/`)
- Modulus (`%`)
- Power (`^`)
- Square Root (`s`)
- Square (`q`)
- Percentage (`p`)
- Division-by-zero protection
- Invalid operation handling
- Continuous calculations without restarting
- Input validation for continuation prompts

## 🛠️ Technologies Used

- **Language:** C++
- **Libraries:** 
  - `<iostream>` for input and output
  - `<cmath>` for mathematical functions

## ⚙️ Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/YOUR-USERNAME/CLI-Calculator.git
```

### 2. Navigate to the project directory

```bash
cd CLI-Calculator
```

### 3. Compile the program

Using GCC:

```bash
g++ main.cpp -o calculator
```

### 4. Run the calculator

**Windows:**
```bash
calculator.exe
```

**Linux / macOS:**
```bash
./calculator
```

## 💻 Usage

Run the program and select an operation using its corresponding symbol or character.

| Input | Operation |
|:---:|---|
| `+` | Addition |
| `-` | Subtraction |
| `*` | Multiplication |
| `/` | Division |
| `%` | Modulus |
| `^` | Power |
| `s` | Square Root |
| `q` | Square |
| `p` | Percentage |

After each calculation, you can choose whether to continue or exit.
